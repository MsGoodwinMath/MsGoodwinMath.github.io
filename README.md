# Algebra 3/4 Class Hub

This is the website for the class notebook and lesson videos. GitHub Pages publishes it automatically.

## Adding or changing things

**Easiest: use the Teacher hub** on the site (`/teacher/`). Lessons, notebook pages, titles and video links you change there show up right away. Nothing to upload here.

**When Claude sends you updated site files:**
1. On this page, select **Add file**, then **Upload files**.
2. Drag in the files or folders Claude sent. Files with the same name replace the old ones.
3. Select **Commit changes**. The site updates in a minute or two.

Don't delete `firebase-config.js`. It connects the site to the live notes.
