Wrap-up

Variables in the denominator

  1. Restrict first: set each denominator ≠ 0.
  2. Same denominator? That denominator is the LCD.
  3. Multiply every term on both sides by the LCD.
  4. Solve like a 1.1 equation.
  5. Check. An answer that breaks a restriction is extraneous. If it was the only answer, there is no solution. done
